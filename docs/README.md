# HarborWatch Docs

This folder contains implementation and operations documentation for HarborWatch.

## Core Guides

- `UPGRADE_AUTOMATION.md` - update detection/apply pipeline, policy semantics, scheduler tasks, and rollback behavior.
- `REVERSE_PROXY.md` - reverse proxy deployment guidance.
- `ROADMAP_v2.md` - roadmap and planned improvements.

## Documentation Scope

Current docs focus on production behavior and operator-facing configuration. As new subsystems are finalized, this folder will be expanded with dedicated guides for security scanning, diagnostics, and AI integration.
